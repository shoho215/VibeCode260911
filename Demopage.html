웹을 만드는
세 가지 언어

HTML5는 구조, CSS3는 디자인, JavaScript는 동작을 담당합니다. 아래 예제를 읽고 버튼을 직접 눌러보세요.

01. HTML5

제목, 문단, 이미지처럼 페이지에 들어갈 내용과 구조를 만듭니다. 태그는 콘텐츠의 역할을 브라우저에 알려줍니다.

<h1>첫 페이지</h1>
<p>반가워요!</p>

02. CSS3

HTML 요소의 색, 크기, 여백, 배치를 꾸밉니다. class를 사용하면 여러 요소에 같은 스타일을 줄 수 있습니다.

.title {
  color: coral;
  font-size: 2rem;
}

03. JavaScript

클릭, 입력 같은 사건에 반응해 화면을 바꿉니다. addEventListener는 이벤트가 발생했을 때 코드를 실행합니다.

button.addEventListener("click", () => {
  message.textContent = "성공!";
});
